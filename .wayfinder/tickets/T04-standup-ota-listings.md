## Question

The software is useless until the hotel actually has **live, connectable listings** on each channel —
and the owner said nothing is live yet. This owner-driven (HITL) prerequisite can proceed **in
parallel** with all the software work and gates go-live (T11). Produce a precise checklist and get it
done:

- **Airbnb:** create the listing(s), complete **identity/property verification**, set status to
  **Listed**, and confirm the property is licensed under an eligible category (boutique hotel / hotel
  / B&B). The brief notes only a **verified + Listed** listing can be connected, and only **one
  Airbnb account** per PMS connection.
- **Booking.com:** register the property, get **Extranet** access, complete onboarding so the
  property can later select our connectivity provider in the Extranet.
- **Expedia:** register on **Expedia Partner Central**, so the property can later enable
  "Expedia Connectivity Settings → System Provider."
- Decide how the **15 rooms map to room-types** on each OTA (how many distinct room-types are we
  selling?) — this feeds the domain model (T05) and mapping (T11).

**Answer records:** which listings exist + their status/verification state, Extranet/Partner-Central
account confirmations, and the room-type breakdown. Flag any that will take real calendar time
(Airbnb verification can lag).
